# UI 시안 브리프: 파라메트릭 파사드 스튜디오

Claude Design에 그대로 붙여넣어 쓰는 브리프입니다. 첨부 이미지 4장은 지금 3D 뷰가 어떻게 보이는지 보여주는 **현재 상태(임시 디버그 페이지)** 이고, 디자인이 아닙니다. 화면 디자인은 처음부터 새로 제안해 주세요.

## 한 줄 설명
파라미터(층수, 베이 수, 창 비율, 리듬 등)로 건물 파사드를 즉석에서 생성하고, 재질을 실시간으로 바꿔볼 수 있는 웹 스튜디오. 건축 전공이 아닌 방문자도 30초 안에 만져볼 수 있어야 합니다. 포트폴리오 사이트입니다.

## 방문자 시나리오 (30초)
1. 페이지를 열면 **이미 파사드 하나가 3D로 떠 있다.** 설명을 읽지 않아도 된다.
2. 슬라이더를 움직이면 파사드가 바로 바뀐다.
3. 프리셋 버튼이나 재질 선택을 눌러 분위기를 바꿔본다.
4. 마음에 들면 PNG로 저장한다.

## 화면 구성

### 탭 2개
`스튜디오` / `AI 갤러리`

### 스튜디오 탭
- **3D 캔버스(주인공):** 화면의 가장 큰 영역. 마우스 드래그로 회전, 휠로 확대. 배경은 밝은 회색 하늘과 바닥 그림자.
- **유형 전환 (3개):** `그리드 창` / `커튼월` / `루버 / 조적`
- **프리셋 버튼 (유형당 2개, 총 6개):**
  - 그리드 창: `5층 규칙형`, `8층 교차 리듬`
  - 커튼월: `오피스 타워`, `세밀한 멀리언`
  - 루버 / 조적: `루버 스크린`, `불규칙 조적`
- **슬라이더/컨트롤 (유형마다 8~9개, 스키마에서 자동 생성되므로 개수가 유형별로 다름):**
  - 공통 6개: `층수`, `베이 수`, `창 비율`, `층고 (m)`, `리듬` (드롭다운: 규칙/교차/그룹/랜덤), `시드`
  - 그리드 창 추가: `1층 상가` (체크박스), `파라펫 높이 (m)`
  - 커튼월 추가: `베이당 멀리언 분할`
  - 루버 / 조적 추가: `층당 루버 개수`, `루버 돌출 (m)`
- **재질 선택 2개:** `주 마감재`, `보조 마감재`. 각각 6종 중 선택: `콘크리트`, `벽돌`, `목재`, `플라스터`, `금속 패널`, `석재`. 재질이 텍스처 미리보기(작은 썸네일)로 보이면 좋겠습니다.
- **버튼:** `랜덤` (시드 변경), `PNG 저장`
- **상태 줄:** 예) `247개 부재 · 21.6m × 17.6m`

### AI 갤러리 탭
- 미리 생성해 둔 SDXL + ControlNet 결과 이미지의 카드 그리드. 스케치 2종(`현대식 박스`, `빌라 입면`) × 재질 4종(`노출 콘크리트`, `적벽돌 파사드`, `통유리 커튼월`, `우드 루버`).
- 카드를 누르면 라이트박스로 크게 보기, `저장` 버튼, `전체 ZIP 저장` 버튼.
- 상단에 짧은 안내문: "GPU에서 미리 생성한 결과입니다. 이 사이트는 GPU 없이 브라우저에서만 동작하도록 다시 만들어졌고, 이 갤러리는 그 이전 실험의 기록입니다." (이 이야기가 프로젝트의 핵심 서사입니다.)

## 제약
- 정적 사이트, 프레임워크 없는 바닐라 JS. 시안은 구현 가능한 수준이어야 합니다 (과한 애니메이션과 외부 폰트 의존은 피하기).
- **모든 화면 문구는 한국어.**
- 모바일(폭 375px)과 데스크톱 둘 다 사용 가능해야 합니다. 모바일에서는 3D 캔버스가 위, 컨트롤이 아래로 쌓여도 좋습니다.
- 다크/라이트 테마는 선택 사항입니다.
- 재사용 가능한 기존 요소: 카드 그리드, 라이트박스(`<dialog>`).

## 시안에서 같이 정해주세요
1. **전체 레이아웃:** 캔버스 + 사이드 패널, 하단 패널, 캔버스 위 플로팅 컨트롤 중 어느 쪽이 맞는지.
2. **`시드` 슬라이더와 `랜덤` 버튼 문제:** 현재는 `리듬`이 `랜덤`일 때만 시드가 눈에 보이는 변화를 만듭니다 (6개 프리셋 중 1개). 방문자가 눌러도 변화가 없으면 고장처럼 보입니다. 선택지:
   - (a) `랜덤` 버튼이 리듬도 `랜덤`으로 바꾼다.
   - (b) `리듬`이 `랜덤`이 아니면 시드 슬라이더를 숨긴다.
   - (c) 파사드 유형 자체에 시드로 달라지는 변화를 넣는다 (구현 비용이 가장 큼).
3. 프리셋 버튼의 위치와 모양 (유형 전환과 한 덩어리인지, 별도 줄인지).
